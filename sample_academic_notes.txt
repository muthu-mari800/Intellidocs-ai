Operating Systems - Lecture Notes
Unit 3: Memory Management
Department of Computer Science, Riverside University
Lecture date: 14 August 2025

Key terms: paging, segmentation, virtual memory, page replacement, thrashing

1. Paging
Definition: Paging is a memory management scheme that divides physical memory into fixed-size blocks called frames
and logical memory into blocks of the same size called pages. Paging removes external fragmentation.
For example, a 16 KB process with 4 KB pages needs 4 pages.

2. Segmentation
Definition: Segmentation divides a program into logical units such as code, data and stack.
Each segment has a base and a limit.

3. Virtual memory
Virtual memory lets a process run even when only part of it is in main memory. It relies on demand paging.
The effective access time formula is: EAT = (1 - p) x memory access time + p x page fault time, where p is the page fault rate.

4. Page replacement
Common algorithms are FIFO, LRU and Optimal. FIFO can suffer from Belady's anomaly.
Thrashing happens when a process spends more time paging than executing.

Important for exam: difference between paging and segmentation, EAT numerical problems, LRU page fault tracing.
Revision tip: practise at least five page replacement problems.
