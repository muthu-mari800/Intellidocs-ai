Smart Attendance System - Project Report
Submitted by: Divya Menon, Final Year B.Tech Information Technology
Guide: Prof. Ramesh Iyer, Riverside University
Date of submission: 20 March 2025

Abstract
This project builds a face-recognition based attendance system for classrooms using Python and OpenCV.

Problem statement
Manual attendance wastes class time and is prone to proxy marking.

Objectives
Automate attendance, reduce errors and generate daily reports.

Methodology
Faces are detected with a Haar cascade and recognised with an LBPH classifier trained on enrolled students.

Implementation
The system has three modules: enrolment, recognition and reporting. The technology stack includes Python, OpenCV and SQLite.

Testing and results
Testing with 60 students achieved a recognition accuracy of 94.2%. Average recognition time was 1.8 seconds per student.

Conclusion
The system reduces attendance time by about 80% compared with manual marking.

Future scope
Add mask detection, a mobile app and cloud synchronisation.
